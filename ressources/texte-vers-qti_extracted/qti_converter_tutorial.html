1. Introduction et présentation

Le Convertisseur Word vers QTI avec Éditeur est une application web permettant de transformer vos questionnaires à choix multiples (QCM) depuis des documents Word ou des fichiers texte vers le format QTI (Question & Test Interoperability), standard international pour les évaluations numériques.

🎯 Objectifs de l'application

  • Convertir automatiquement les QCM depuis Word (.docx, .doc) ou texte (.txt)
  • Éditer et corriger les questions avant export
  • Générer des fichiers QTI compatibles avec les plateformes d'e-learning
  • Prendre en charge les questions à réponse unique (QRU) et multiple (QRM)

📥 Import flexible

Importe depuis Word, fichiers texte, ou par glisser-déposer. Extraction automatique du contenu textuel.

✏️ Éditeur intégré

Modifiez vos questions directement dans l'interface avec aperçu en temps réel.

📊 Validation automatique

Détection des erreurs de format et suggestions d'amélioration.

📦 Export QTI standard

Génération de fichiers ZIP compatibles avec Moodle, Canvas, et autres LMS.

3. Format des documents source

L'application reconnaît un format spécifique pour les questions. Respecter ce format est essentiel pour une conversion réussie.

Structure de base

📝 Format standard
QRU : Votre question à réponse unique ?
A : Première proposition
B : Deuxième proposition *
C : Troisième proposition

QRM : Votre question à réponses multiples ?
A : Première proposition *
B : Deuxième proposition
C : Troisième proposition *
D : Quatrième proposition

Règles de formatage

En-tête des questions

  • QRU : pour les questions à réponse unique
  • QRM : pour les questions à réponses multiples
  • Le deux-points (:) après QRU/QRM est obligatoire
  • Insensible à la casse (qru, QRU, Qru acceptés)

Choix de réponses

  • Commencer par une lettre (A, B, C, D, E)
  • Suivi de : (espace, deux-points, espace)
  • L'astérisque (*) indique une réponse correcte
  • Placer l'astérisque après le texte de la réponse

✅ Exemple correct

QRU : Quelle est la capitale de la France ?
A : Londres
B : Berlin
C : Paris *
D : Madrid

❌ Exemples incorrects

QRU Quelle est la capitale ? (manque le :)
A- Paris * (mauvais séparateur)
B: Réponse * sans espace
QRM sans question
A : Choix

Variations acceptées

L'application tolère certaines variations mineures :

  • A), A., A- comme séparateurs
  • Espaces supplémentaires autour des éléments
  • Lignes vides entre les questions (recommandé)
  • Casse mixte pour les lettres de choix

5. Onglet 1 : Importer

Le premier onglet permet d'importer vos documents source et de les convertir en texte éditable.

Méthodes d'importation

Méthode 1 : Glisser-déposer

  1. Ouvrez l'explorateur de fichiers
  2. Glissez votre fichier dans la zone de dépôt
  3. Relâchez le fichier sur la zone bleue
  4. L'importation démarre automatiquement

Méthode 2 : Sélection manuelle

  1. Cliquez sur Choisir un fichier
  2. Naviguez vers votre fichier
  3. Sélectionnez et confirmez
  4. L'importation démarre automatiquement

Processus d'importation

Pour les fichiers Word (.docx, .doc)

  • Extraction automatique du texte brut
  • Suppression du formatage (gras, italique, etc.)
  • Préservation de la structure en paragraphes
  • Bascule automatique vers l'onglet "Éditer"

Pour les fichiers texte (.txt)

  • Lecture directe du contenu
  • Détection automatique de l'encodage
  • Chargement immédiat dans l'éditeur

⚠️ Problèmes courants à l'importation

  • Fichier corrompu : Réessayez avec une version sauvegardée
  • Encodage incorrect : Sauvegardez en UTF-8 depuis votre éditeur
  • Taille excessive : Divisez en plusieurs fichiers
  • Format non supporté : Copiez-collez le contenu dans un .txt

L'onglet d'édition offre un environnement complet pour réviser, corriger et améliorer vos questions avant l'export.

Interface de l'éditeur

L'interface est divisée en deux panneaux :

  • Panneau gauche : Éditeur de texte avec outils
  • Panneau droit : Aperçu des questions analysées

Boutons de l'éditeur

Bouton Fonction Description
🔧 Auto-formater Formatage automatique Corrige la structure des questions selon le format standard
🧹 Nettoyer Nettoyage du texte Supprime caractères parasites, normalise espaces et retours ligne
➕ Ajouter exemple Question d'exemple Insère un modèle de question pour référence

🔍 Analyser le texte Analyse et validation Parse le texte et met à jour l'aperçu des questions

Fonctions détaillées

🔧 Auto-formater

Cette fonction applique les corrections suivantes :

  • Normalise les en-têtes QRU/QRM avec deux-points
  • Uniformise les séparateurs de choix (A :, B :, etc.)
  • Corrige la casse des lettres
  • Ajoute des espaces manquants
  • Sépare visuellement les questions
Avant auto-formatage
qru question mal formatée
a)réponse1
b réponse2*
c.réponse3
Après auto-formatage
QRU : Question mal formatée
A : réponse1
B : réponse2 *
C : réponse3

🧹 Nettoyer

Le nettoyage traite :

  • Suppression des backslashes parasites
  • Normalisation des apostrophes et guillemets
  • Remplacement des caractères spéciaux
  • Fusion des espaces multiples
  • Limitation des lignes vides consécutives

Aperçu en temps réel

Le panneau de droite affiche :

  • Compteur de questions détectées
  • Aperçu visuel de chaque question
  • Type de question (QRU/QRM)
  • Réponses correctes marquées d'une coche
  • Numérotation automatique

Détection et résolution d'erreurs

❌ Erreurs communes détectées

  • Question sans texte : En-tête QRU/QRM vide
  • Choix sans réponse : Lettre suivie de rien
  • Pas de bonne réponse : Aucun astérisque trouvé
  • Choix orphelin : Réponse sans question associée

Lorsque des erreurs sont détectées, une section d'avertissement apparaît avec la liste précise des problèmes à corriger.

8. Format de sortie QTI

L'application génère un fichier ZIP contenant tous les éléments nécessaires pour importer vos questions dans une plateforme d'e-learning compatible QTI.

Contenu du fichier ZIP

Structure du fichier de sortie

MonQuestionnaire_QTI.zip
├── pool.xml                    # Fichier de configuration du test
├── QUESTION_1.xml              # Question individuelle n°1
├── QUESTION_2.xml              # Question individuelle n°2
├── QUESTION_3.xml              # Question individuelle n°3
└── ...                         # Autres questions

pool.xml - Fichier de configuration

Ce fichier principal contient :

  • Métadonnées du test : Titre, identifiant, description
  • Structure générale : Organisation en sections
  • Références aux questions : Liens vers chaque fichier XML
  • Configuration d'affichage : Mode de navigation, soumission
  • Pondération : Poids de chaque question (par défaut : 1 point)

Fichiers de questions individuelles

Chaque question génère un fichier XML contenant :

  • Identificateur unique : SINGLECHOICE_QUESTION_X ou MULTIPLECHOICE_QUESTION_X
  • Type de question : Réponse unique ou multiple
  • Énoncé : Texte de la question avec formatage HTML
  • Choix de réponses : Toutes les propositions avec identifiants
  • Réponses correctes : Marquage des bonnes réponses
  • Configuration de scoring : Attribution des points

Plateforme Compatibilité Import recommandé Notes
Moodle ✅ Excellente Banque de questions Support natif QTI 2.1
Canvas ✅ Très bonne Import de quiz Conversion automatique

Format XML généré

Exemple de question QRU générée
<?xml version="1.0" encoding="UTF-8"?>
<assessmentItem xmlns="http://www.imsglobal.org/xsd/imsqti_v2p1" 
                identifier="SINGLECHOICE_QUESTION_1" 
                title="Q1" 
                adaptive="false">
    
    <responseDeclaration identifier="RESPONSE" cardinality="single" baseType="identifier">
        <correctResponse>
            <value>CHOICE_1_C</value>
        </correctResponse>
    </responseDeclaration>
    
    <itemBody>
        <choiceInteraction responseIdentifier="RESPONSE" maxChoices="1">
            <prompt>
                <p>Quelle est la capitale de la France ?</p>
            </prompt>
            <simpleChoice identifier="CHOICE_1_A">
                <p>Londres</p>
            </simpleChoice>
            <simpleChoice identifier="CHOICE_1_B">
                <p>Berlin</p>
            </simpleChoice>
            <simpleChoice identifier="CHOICE_1_C">
                <p>Paris</p>
            </simpleChoice>
        </choiceInteraction>
    </itemBody>
</assessmentItem>

9. Résolution de problèmes

Problèmes d'importation

❌ "Erreur lors de la lecture du fichier Word"

Causes possibles :

  • Fichier corrompu ou protégé par mot de passe
  • Version Word très ancienne (pré-2007)
  • Document avec macros ou contenu actif

Solutions :

  • Enregistrez le document au format .docx standard
  • Supprimez la protection et les macros
  • Copiez le contenu dans un nouveau document
  • Exportez en .txt depuis Word

❌ "Format non supporté"

Solutions :

  • Convertissez en .docx, .doc ou .txt
  • Évitez PDF, RTF, ODT
  • Utilisez "Enregistrer sous" depuis votre traitement de texte

Problèmes d'analyse

⚠️ "Aucune question détectée"

Vérifications :

  • Présence de QRU : ou QRM : en début de ligne
  • Format des choix : A : texte
  • Au moins une réponse avec astérisque *
  • Espacement correct entre éléments

Utilisation des outils :

  • Bouton "Nettoyer" pour les caractères parasites
  • Bouton "Auto-formater" pour corriger la structure
  • Comparer avec le format d'exemple fourni

⚠️ "Questions sans bonne réponse"

Correction :

  • Ajoutez * après le texte de la bonne réponse
  • Vérifiez que l'astérisque n'est pas séparé par un espace
  • Pour QRM : plusieurs * sont autorisés
  • Utilisez l'aperçu pour vérifier visuellement

Problèmes d'export

❌ "Erreur lors de la génération du ZIP"

Causes et solutions :

  • Mémoire insuffisante : Réduisez le nombre de questions
  • Navigateur bloquant : Autorisez les téléchargements
  • Caractères interdits : Simplifiez les titres et identifiants
  • Questions invalides : Corrigez toutes les erreurs détectées

Problèmes d'importation dans le LMS

⚠️ "Import QTI échoue dans Moodle/Canvas"

Vérifications :

  • Décompressez le ZIP et vérifiez le contenu
  • Identifiants de test uniques dans la plateforme
  • Droits d'administration suffisants
  • Limites de taille du LMS respectées

Alternatives :

  • Importez les questions par petits groupes
  • Modifiez les identifiants en cas de conflit
  • Consultez la documentation spécifique du LMS

10. Conseils et bonnes pratiques

Préparation du document source

✅ Recommandations de préparation

  • Structure claire : Une question par bloc, séparée par une ligne vide
  • Numérotation cohérente : A, B, C, D, E dans l'ordre
  • Texte simple : Évitez formatage complexe, tableaux, images
  • Révision manuelle : Relisez avant importation
  • Sauvegarde : Conservez une copie de travail

Optimisation du workflow

  1. Import initial
    • Testez d'abord avec 2-3 questions
    • Validez le format avant d'importer tout
    • Préférez .txt pour éviter les problèmes de formatage Word
  2. Phase d'édition
    • Utilisez "Nettoyer" en premier
    • Puis "Auto-formater" si nécessaire
    • Corrigez manuellement les cas spéciaux
    • Vérifiez l'aperçu après chaque modification
  3. Export et test
    • Configurez des métadonnées descriptives
    • Testez l'import dans votre LMS avec un sous-ensemble
    • Vérifiez l'affichage des accents et caractères spéciaux

Gestion des gros volumes

💡 Stratégies pour de nombreuses questions

  • Division par thèmes : Créez plusieurs fichiers QTI spécialisés
  • Traitement par lots : 20-50 questions maximum par session
  • Validation progressive : Vérifiez chaque lot avant de continuer
  • Nomenclature cohérente : Identifiants prévisibles (THEME_001, THEME_002...)

Qualité des questions

Critères d'une bonne question QCM

  • Énoncé clair : Question précise et non ambiguë
  • Distracteurs plausibles : Réponses incorrectes crédibles
  • Longueur équilibrée : Choix de taille similaire
  • Une seule bonne réponse : Pour les QRU
  • Réponses indépendantes : Chaque choix se suffit à lui-même

Pièges à éviter

  • Négations multiples : "Lequel n'est pas incorrect..."
  • Indices dans l'énoncé : Mots qui orientent vers la réponse
  • Réponses "toutes les réponses ci-dessus" : Généralement à éviter
  • Longueurs révélatrices : Bonne réponse beaucoup plus longue

Maintenance et révision

✅ Cycle de vie des questionnaires

  • Version initiale : Test avec petit groupe d'utilisateurs
  • Analyse des résultats : Identification des questions problématiques
  • Révision : Modification du document source
  • Re-conversion : Nouvelle génération QTI
  • Déploiement : Remplacement de l'ancienne version
